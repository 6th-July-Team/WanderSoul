## WanderSoul

<img width="1916" height="1080" alt="타이틀 스샷" src="https://github.com/user-attachments/assets/7611adb6-4d71-4db1-8256-0dbf6c55c832" />

- **장르 :** 3D 캐러밴 RPG 게임
- **플랫폼 :** PC
- **게임 엔진 :** Unity
- **게임 한 줄 요약 :** 마력의 폭주로 멸망의 위기에 놓인 세상에서 특별한 능력으로 마력 생명체를 조종하는 모험가가 되어 마을과 마을 사이의 위험한 교역로를 돌파하는 용병으로 활동하는 게임

### 스토리
> ‘소울’이라고 불리는 신비한 에너지가 존재하는 세계.
> 인간의 왕국 ‘루인델’만은 주어진 평화에 만족하지 못했다. ‘소울’을 정제해서 인간의 명령에만 따르는 인공 생명체를 창조하려는 시도하였고, 그것이 모든 재앙의 시작이었다.
>
> ‘그것’들은 각 지역을 초토화시키며 아름다웠던 세계를 뒤틀린 환경으로 변이시켰고, ‘원더링(Wandering)’이라고 불렀다.
> ‘원더링’에 접촉해도 영향을 받지 않으며 ‘뒤틀린 소울’에 면역을 가지고, 무너져 가는 세계를 정처없이 떠도는 자유로운 이들이 존재했다.
> 
> 그들을 ‘원더소울(WanderSoul)’이라고 불렀다.

### 조작법
- 이동 : WASD
- 공격: 왼클릭(기본 공격), 우클릭(특수 공격), R(궁극기)
- 대쉬 : Shift
